\subsection*{三点共线与三线共点}
公理3：如果两个不同的平面有一个公共点, 那么它们有且只有一条过该点的公共直线

公理3的理解：
\begin{dingautolist}{172}
    \item 如果两个相交平面有两个公共点，那么过这两点的直线就是他们的交线
    \item 如果两个相交平面有三个公共点，那么这三点共线
    \item 如果两个平面相交，那么一个平面内的直线和另一个平面的交点必在这两个平面的交线上
\end{dingautolist}

\subsection*{线线平行}
证明线线平行涉及到的方法如下：
\begin{dingautolist}{172}
    \item 平面几何：中位线、平行四边形
    \item 平行公理（公理4）：平行的传递性
    \item 线面平行的性质定理：线面平行中蕴含着线线平行
    \item 线面垂直的性质定理：垂直和平行可以相互转化
    \item 面面平行的性质定理：面面平行中蕴含着线线平行
\end{dingautolist}
